# Green-CSharp
A tapermonkey script that brings back the old (and better) C# colors to github

## Why?
I just don't like the new color, thats it.

## How to use
1. Install tapermonkey either on a [chrome based browser]() or [firefox based browser]()
2. Install the script by making a new script then copying the code inside ```green-cs.js``` and pasting into the tapermonkey editor
3. Save the changes then go back into github and refresh the page with **Ctrl + Shift + R** to refresh the cache
4. That's it! the old C# green should be bought back!

## Issues
If i missed a part of github that still uses the new C# color then feel free to write an issue or make a pull request with the fix!
